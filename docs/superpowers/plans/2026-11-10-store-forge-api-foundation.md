> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the shared NestJS foundation (database, security, API contracts, provisioning) so Santu can build his modules independently, with every approved decision D-001 to D-025 proven by real test output.

## 3. Evidence framework
```

Evidence Type is one of UNIT, INT (PGlite), SEC, DB/RLS, API (request and response), SWAGGER (spec plus screenshot), CI (run log), MANUAL-LIVE, DOC. A path is written only after the file exists and is readable.
- Test output: `npx vitest run <config> --reporter=verbose 2>&1 | tee screenshots/store-forge-api/<PR>/test-output/<name>.txt` plus `--reporter=json --outputFile=...`. Never edited; totals in any report come from the JSON, never estimated.

No frontend workflow consumes this API in PR-A to PR-C (D-006 OPEN; Next.js header forwarding is separate integration work), so no workflow screenshots are planned for them. - Swagger evidence: run the real pipeline (`SWAGGER_ENABLED=true`; probe routes from `test/support`), capture `/api/docs` with Playwright from a scratch script outside the repo (record its command in the index), never show a token in the Authorize dialog, keep the generated `/api/docs-json` in `test-output/`. No installed browser means BLOCKED.
- Closeout statuses. DONE: implementation and every applicable verification passed with evidence in the index. PARTIALLY VERIFIED: some required verification is missing. FAILED: behaviour contradicts the AC (stays FAILED until fixed and re-run). BLOCKED: a prerequisite is unavailable. NOT VERIFIED: evidence insufficient. NOT IMPLEMENTED: code absent. A passing unit test alone is not DONE; a Playwright pass without the screenshot is not DONE where screenshots apply; a skipped test is never PASS (`.only` fails CI; `.skip` needs a BLOCKED reason naming the AC).
- Final closeout per PR: verify every index path exists and is readable, run the full suite, then fill Actual Result and Status from that run. Sanitize before commit: grep for `postgres://`, `eyJ`, `sb_`, `apikey`, project refs; none may appear.

export type Database = PostgresJsDatabase<typeof dbSchema>;
export type DbTx = Parameters<Parameters<Database['transaction']>[0]>[0];
